# LuminaStudy AI - Website starter

This is a simple mobile-friendly website version of the sign-in screen described in the supplied implementation plan.

## Publish free with GitHub Pages

1. Extract this ZIP file.
2. Open your GitHub repository.
3. Choose **Add file** -> **Upload files**.
4. Upload `index.html` (not the ZIP itself).
5. Scroll down and choose **Commit changes**.
6. Open **Settings** -> **Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose branch `main` and folder `/(root)`, then click **Save**.
9. Wait a few minutes and refresh the Pages screen. Open the published website link.

## Important

This is a front-end design starter. The Google button is a placeholder and does not sign users in yet. Real Google Sign-In requires a Firebase project, app configuration, and authorized domain setup. The supplied implementation plan describes a sign-in screen; it does not contain the full study workspace or its features.
